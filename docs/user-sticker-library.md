# 上传与编辑表情

桌宠右键 → **表情与互动 · 上传 / 编辑**。

## 上传与资料

1. 点击右上角 **＋ 上传表情**，选择 GIF 或 PNG。
2. 选择一二、布布、双人同框或场景，填写名称、动作、对方可能做什么以及位置说明。
3. 点击底部 **保存资料**。单人表情保存后可继续打开 **关联关系**。

角色保存后固定，以免已有搭配突然变成同一个角色。首帧在编辑器预览，完整动画在表情库预览。新表情会加入“我的上传”，启用的单人表情也会参与自然活动。

支持最大 50 MB、2048×2048、500 帧，累计最多 1.6 亿像素。GIF 保留原帧时长（小于 20 ms 按 20 ms 播放，未指定时按 100 ms）。保留上传原文件，不自动抠图、改画或缩放。

## 配置搭配

选择任意表情 → **编辑资料 / 关联关系** → **关联关系**：

- 点击已有关系修改，或点 **＋ 新增关联候选**。
- 搜索另一位的编号、名称或动作，选择对应表情；选择框下方可看首帧。
- 选择“与左右无关”“一二在左，布布在右”或“布布在左，一二在右”，补充说明，设置共同播放秒数。
- 勾选触发方：可以单向触发，也可以互相触发。
- 选择两个互动菜单的入口，点击 **保存这条关联**。底部保存按钮会根据当前标签页切换：关联页保存关系，资料页保存名称、描述和素材菜单配置。
- 重复新增即可配置多个候选。每次从可用候选中选一组播放，同一角色不会同时分身播放多个表情。

自动触发需要打开“自动互动”，双方可见、空闲且冷却结束。拖动、抛掷或打开右键菜单时不会抢占角色。手动点选互动可结束普通表情，再按站位走到对应位置。与左右无关时沿用当前左右顺序。

已有追逐关系保留其专用方向和镜像配置；要换另一套素材，请新增普通关联。现有先后回应场景保留原运行逻辑；当前编辑器新增的单人搭配为同时播放。

## 三个右键栏目

- **切换动作**：资料页勾选。默认每位角色保留站立、左右走路和五个常用原表情。
- **原表情关联互动** / **和对方互动**：单人素材在关联页逐条勾选；双人同框或场景在资料页直接勾选。两个栏目分别默认精选六组。
- 取消菜单勾选只是隐藏入口；取消关系的“启用”会停止它的触发，原素材保留。
- 表情库的“停用这个表情”同时阻止依赖它的搭配，之后可以恢复。

## 保存位置

个人上传、描述覆盖、关联和菜单设置保存在 `%APPDATA%\YierPet-Windows\UserLibrary`。备份或迁移时复制整个文件夹；全局开关和停用清单另存于相邻的 `settings.json`。内置资源不被覆盖。

系统哨兵菜单、CPU / 内存 / 电量 / 磁盘监测与对应提示已移除。久坐、喝水、深夜与视频播放器前台停留的健康提醒保持原设置。
