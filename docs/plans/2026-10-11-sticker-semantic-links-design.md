# 原动作移动与逐项语义联动

用户要求用 wx-0150 / wx-0183 替换生成移动，并为每张现有原表情说明动作和画外另一方可能的行为，再据现成素材联动。

## 数据与证据

- 活跃素材恢复为 522 张原图；4 个生成移动条目退出加载清单。保留源文件历史，不再出现在素材库或任何状态映射中。
- `semantics.tsv` 是逐项人工阅读原始帧后的编辑源，字段为编号、画面动作、另一方可能回应、类别。后者明确是编排设想。
- `tools/review_sticker_semantics.py` 为每张原图输出按时长四等分采样；小锤、走路、角色分类疑点另查更密集帧。不能将抽样审阅写成逐帧全量人工审阅。
- `tools/prepare_semantic_links.py` 校验覆盖并输出 `semantics.json`、可读总表及独立联动清单；候选配对只用人工明确列出的 ID，不按同色或关键词自动猜关系。
- 修正采样发现的分类错误，包括被误当成布布的饼点以及后半段才出现一二的动画。

## 播放

- wx-0150 / wx-0183 原画朝左，左行直接使用，右行只在显示时水平镜像；不重画、不改原帧或延时。
- `simultaneous`：两只靠近后同时开始各自原动画，统一结束时间，帧速保持原样。
- `chase`：一二使用带道具原表情，布布使用 wx-0183；前后排列、同速移动，抵达屏幕边缘就结束而非交换前后瞬移。文字素材不镜像。
- 桌面随机行为和素材库播放都尝试按触发 ID 找关联；对方正播放、拖动、抛掷、打开菜单、被隐藏、素材被停用、自动互动关闭或仍在冷却时，保持当前角色独立播放。
- 联动冷却只约束联动，不阻断任意一方独立表情。拖动、停用或隐藏会取消关联并恢复独立。
- 双人同框原表情继续走原合成画面播放，不拆成两个有重复人物的窗口。

## 可管理性与验证

素材库显示动作、回应设想、类别和联动编号，支持按这些内容搜索，增加已配对筛选和显式联动按钮。单张停用会让所有依赖规则不可用。

验证覆盖：522 行完整性、匹配角色、依赖闭包、原始左右帧镜像、生成移动无入口、同步起播、追逐相对位置/边缘、忙碌回退、停用/隐藏/拖动中断、独立行为保留、安装文件哈希。临时冒烟项目用完删除，只留结果记录。
