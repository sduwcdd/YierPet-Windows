# 一二和布布：双角色桌宠第一版

## 已选方向

用户选择更贴近原作者表情包比例、配色和线条的画风，以及“独立活动＋专用双人动画”。在现有 Windows WPF 项目中迭代。

## 本版内容

- 一二与布布分别拥有透明窗口，可独立拖动、抛掷、播放动作和随机散步。
- 两者均有待机、左右行走、挥手、跳跃、委屈、等待、工作、阅读动画。
- 右键“和对方互动”：招呼、抱抱、贴贴（依偎）。招呼保持独立窗口；抱抱、依偎使用专门绘制的双人逐帧图集。
- 相互靠近后再互动，结束后恢复独立状态。点击双人画面的左/右侧，可分别将一二/布布拖走。
- 自动互动可关闭；布布跟随一二可单独开启。默认两只独立活动，不默认跟随。
- 自动互动候选间隔为 35–65 秒，拖动、抛掷、菜单操作和短动作优先。结束后设置冷却，避免拖近反复触发。
- 两只都能单独隐藏，但菜单不允许同时隐藏最后一只；提供回到主屏幕右下角的入口。
- 提醒服务由协调器唯一持有，角色共享设置，避免重复提醒和覆盖彼此设置。

## 实现

`DuoCoordinator` 管理独立、接近、招呼、双人动画四种状态。一个低频健康检查累计器负责原提醒服务，一个 25ms 调度计时器推进协调移动；动画帧保持原来的逐帧计时方式。

接近与跟随使用经过时间计算位移。双人动画每 0.5 秒切换关键帧；结束、用户打断、隐藏或提醒都恢复角色窗口。关闭程序会清理窗口和计时器。

`SpriteAnimator` 按角色选择图集，读取实际透明边界并统一脚底位置；左向行走从右向帧镜像。图集未覆盖原始 `spritesheet.png`，Swift 和 Codex 原生宠物包不受本次改动影响。

## 素材

四张带 alpha 通道的 AI 重绘图集位于 `windows/YierPet.Windows/Assets/*-v1.png`。它们是本项目的首版动画素材，不是作者官方发布的动画包。生成方式、参考和提示词见 `docs/duo-asset-prompts.md`。

## 验证与边界

- Release 编译通过，无警告、无错误。
- 临时 WPF 冒烟程序验证 72 个角色帧、8 个双人帧、透明像素与非空内容；验证旧设置兼容、三种互动进入及恢复、接近取消、双人画面鼠标捕获转交、隐藏伙伴、跟随、自动开关及菜单入口。
- 使用实际 WPF 控件离屏渲染检查一二、布布、拥抱和依偎。
- 最终冒烟共 107 项断言通过，追加检查左右屏幕边缘的集合位置、抛掷优先级及反弹落地恢复。临时测试关闭真实健康提醒，避免虚拟时间推进与真实 UI 动画计时相互干扰。
- 这些检查不等同于长期桌面使用验收。多显示器、混合 DPI、长时间运行、用户对外观与动作流畅度的认可仍待实际体验。
- 延续原程序主要按主屏幕工作区约束移动的行为。本轮不加入 AI 对话、换装、联网功能或后台服务。

临时冒烟源码、可执行文件、截图和结果文本在验证后删除。
