# YierPet Windows 移植设计

## 目标

在不改变原项目 macOS 实现的前提下，新增一个可在 Windows 10/11 运行的原生桌宠。Windows 版本复用原始 8×9 精灵图与动作节奏，并提供透明置顶窗口、拖拽抛掷、气泡、随机行为、健康提醒和系统状态提醒。

## 技术方案

采用 .NET 8 WPF，代码位于 `windows/YierPet.Windows`。WPF 可以原生创建无边框、透明、不显示任务栏图标且始终置顶的窗口；Windows API 仅用于读取空闲时间、前台进程、CPU、内存和电量，无需辅助功能或屏幕录制权限。

原始 WebP 图集被无损转换成 PNG，作为 WPF 内嵌资源。动画器按原项目的 192×208 单元格、8 列×9 行和每帧时长裁切显示。设置保存于 `%APPDATA%\\YierPet-Windows\\settings.json`，用于保存随机行为与各项提醒的开关。

## 功能映射与边界

| macOS 功能 | Windows 实现 |
| --- | --- |
| 无 Dock 图标的悬浮窗口 | 无边框、透明、Topmost、无任务栏图标的 WPF 窗口 |
| 9 种图集动画 | 原图集和同等帧序、时长 |
| 拖拽与抛掷 | 指针采样、重力和边界反弹 |
| 久坐/喝水/深夜提醒 | `GetLastInputInfo` 和本地计时 |
| 前台视频 App 提醒 | 通过前台进程名识别已知播放器；不检查浏览器网页内容 |
| CPU/内存/电量/磁盘提醒 | `GetSystemTimes`、`GlobalMemoryStatusEx`、`GetSystemPowerStatus`、`DriveInfo` |

浏览器内具体网站的识别需要额外的浏览器扩展或屏幕/辅助功能权限，因此本移植版有意不实现；其余功能均保持零额外权限。

## 验证

1. `dotnet build` 编译 WPF 项目。
2. 启动应用，确认窗口透明、置顶、动画播放、左键拖拽和右键菜单可用。
3. 使用右键菜单中的“测试提醒”核对气泡和各提醒路径。
4. 发布 win-x64 版本并在本机从发布目录启动。
