# 本地表情与互动编辑

用户授权范围：上传 GIF/PNG、编辑资料、选择多个联动候选及左右要求、配置三个右键栏目；移除系统哨兵，保留健康提醒。

沿用现有 WPF 素材库，不引入服务端。新增“上传表情”和“编辑资料 / 关联”入口，编辑器分为资料、关联规则两页。单人素材只允许与另一个角色组成关联；多个候选每次选一个，避免同一角色重复出现。内置素材也可编辑说明和关联，原图保持不变。双人同框图直接配置自己的站位和菜单入口。

个人素材、编辑覆盖及菜单配置存入 AppData/YierPet-Windows/UserLibrary，与安装目录内置资源分开；保存采用临时文件替换。关联包含启用状态、触发方、对方素材、站位、菜单归属。停用关系可恢复，停用素材使依赖关系不可用。

GIF 导入使用 Windows 图像解码器，按帧偏移、透明色及 disposal 规则合成完整帧，再分装 PNG 图集；保留时长，不依赖 Python。参考微软 WIC 元数据规范：https://learn.microsoft.com/en-us/windows/win32/wic/-wic-native-image-format-metadata-queries 。校验尺寸、帧数、体积，并在后台导入。

右键切换动作只保留站立、两个真实行走动作和每个角色五个常用原表情。两个互动菜单各预置约六组，用户可增减。菜单点击先关闭菜单并解除忙碌状态，再执行动作。

验证覆盖 GIF disposal 0/1/2/3、部分帧及透明背景、导入/编辑/重启读回、多候选与左右入场、菜单点击、停用关系、内置素材回归；删除临时冒烟文件后部署。
