# 一二和布布 v0.0.3

## 语音工坊与离线健康提醒

- 新增语音工坊：分别配置一二、布布的声音，输入新台词，生成、试听、下载 WAV，并归档角色模型与参考录音。
- 默认按需加载：启动桌宠、打开语音工坊、检查准备情况均不加载生成模型。点击“生成并试听”才启动 CPU 推理，完成、失败、取消或关闭工坊后结束本次服务；应用异常退出时也监测退出并清理推理进程。
- 增加“取消生成”，保留高级设置中的手动外部服务模式。外部服务由用户自行启动和关闭。
- 支持默认声音预设和预设导入，提供详细使用教程；轻度清晰化保留原音并另存处理版本。
- 为现有 16 句健康提醒准备两位角色的配音，共 32 段；原音和轻度清晰化版共 64 个 WAV 随 EXE 提供。健康提醒直接播放本地文件，不加载模型，也不需要 Python 或联网。

**使用范围：** EXE 包含桌宠、522 张原表情、225 条互动规则、语音工坊和提醒音频，不包含训练权重、参考录音或 GPT-SoVITS / Python 环境。生成新的台词需要按[语音教程](https://github.com/sduwcdd/YierPet-Windows/blob/v0.0.3/docs/voice-guide.md)准备环境。模型文件就绪不代表音色效果已经验收；轻度清晰化不能保证修复读错字或电音。按需模式每次都重新加载，生成期间仍有 CPU 和内存开销。

## 角色互动调整

- 默认待机和回到右下角时，布布在左、一二在右，面对面站立。
- 修复布布单击缺少动作的问题，改为原表情飞吻回应。
- 将一二抛向布布附近时，若在下落且首次撞地前被空闲的布布接住，播放 `wx-0401` 抱起转圈；未接住时保留原有摔落反馈。
- 保留原表情下载、筛选 ZIP 导出、自定义表情与关联关系等既有功能。

## 下载与更新

下载 **YierPet-Windows-v0.0.3-win-x64.exe**。在旧版角色上右键 → 退出，再运行新版。用户设置、上传表情和声音配置仍在 `%APPDATA%\YierPet-Windows`，更新前可备份该目录。

完整 EXE 自带 .NET 运行时及内置素材，适用于 Windows 10 / 11 x64，无需安装 .NET。当前未签名，不提供 ARM64 原生构建。

附件 `SHA256SUMS.txt` 用于下载校验，`verification.json` 记录独立 EXE 的素材、原文件导出、隔离数据读写及提醒配音完整性检查；该检查不代替其他电脑上的新台词生成或人工听感验收。
