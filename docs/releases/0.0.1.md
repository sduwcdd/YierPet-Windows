# 一二和布布 v0.0.1

首个完整单文件 Windows x64 发布版。

## 下载和运行

下载下方 `YierPet-Windows-v0.0.1-win-x64.exe`，放到固定目录后双击运行。无需另外安装 .NET、Python 或下载素材。首次启动会解包，请稍等；在桌宠身上右键打开菜单，右键“退出”结束使用。

支持 Windows 10 / 11 x64。程序没有任务栏按钮，角色默认在主屏幕右下角附近。当前 EXE 未做代码签名，可使用随附 `SHA256SUMS.txt` 核验下载文件。

## 功能

- 一二和布布独立活动、原图走路、拖拽、抛掷及跟随。
- 522 张内置原表情，225 条互动规则，包含 114 组单人素材搭配。
- 固定左右的互动先到对应位置；支持无左右要求及追逐关系。
- 上传 GIF / PNG，编辑说明、多个关联候选、触发方、左右关系与三个右键栏目。
- 保留可关闭的健康提醒；移除系统哨兵。

## 数据与更新

上传和设置保存在 `%APPDATA%\YierPet-Windows`。升级前退出旧版、备份该目录，再使用新 EXE；无需复制运行时或素材目录。

详细操作见仓库 README 和 `docs/user-sticker-library.md`。Release 的 `Source code` 文件是源码，不是面向普通用户的安装包。

随附 `verification.json` 记录本次完整 EXE 的自动验证结果。
