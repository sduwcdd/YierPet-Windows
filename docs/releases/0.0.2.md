# 一二和布布 v0.0.2

## 新增原表情下载

- 表情库选择任意内置或个人上传表情，点击“下载原文件”，保留原始 GIF / PNG / JPG 与完整动画。
- 点击“导出筛选”，将分类和搜索的全部匹配项导出 ZIP，附动作说明、来源、哈希与包内关联配置。
- 兼容旧版本的个人上传记录。原文件缺失或哈希不符时停止导出。
- 完整 EXE 内包含内置原文件，下载功能无需联网。

下载 `YierPet-Windows-v0.0.2-win-x64.exe`，退出旧版后双击新版运行；个人数据仍保存在 `%APPDATA%\YierPet-Windows`。

本版继续包含此前的 522 张内置表情、225 条互动规则。新提供的“450+大合集”文章尚因微信验证页未能读取，没有纳入本版；不会以旧素材冒充新导入。

附件 `SHA256SUMS.txt` 与 `verification.json` 提供下载校验和发布包自检结果。当前 EXE 未签名，仅提供 Windows x64 构建。
