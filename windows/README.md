# YierPet Windows 移植版

这是 [YierPet](../README.md) 的 Windows 原生实现，使用 .NET 8 WPF 编写。Windows 版支持一二和布布独立活动、原始表情动画与关联互动；原 macOS 与 Codex 宠物包仍使用各自原有素材。

## 公众号原表情素材库

- 当前总计 **522 个原图条目**：微信 492 项、GetStickerPack 30 项。生成跑步已退出清单；素材库可筛选原图走路、GetStickerPack 或已配对单人表情。
- GetStickerPack 的 30 项均为 512×512 静态 PNG，完整导入并校验原图像素，编号 `gsp-0001` 至 `gsp-0030`；10 个双人静态画面可手动播放，不伪造动态中间帧。
- 左右移动分别使用 **wx-0150（一二）/ wx-0183（布布）**，原图朝左，右行仅在显示时镜像。停用后回退批准的静态待机；不重新启用历史生成跑步。
- 全部 522 项有画面动作、另一方可能回应、类别及关联编号。可在素材库按“锤”“拍照”“喝饮料”等搜索，也可阅读[完整说明](../docs/art-direction/sticker-semantics.md)。
- 114 组跨单人素材联动，其中 6 组是追逐。随机或手动触发其中一个时，双方空闲且开启自动情侣互动便靠近后同步播放。追逐保持一二在后、布布在前，至屏幕边缘停止；其他组合各自保留原帧速。素材库的“播放选中联动”可以手动指定组合。
- 对方在播放、拖动、抛掷、开菜单、被隐藏，或关联素材停用、自动互动关闭、处于联动冷却时，当前表情继续独立播放。回应说明属于应用编排设想，不声称是原作者剧情；局部道具不明确的条目已单独注明。

- 已导入用户指定的[当前文章](https://mp.weixin.qq.com/s/CaQ-fa957yZ8h8b_sEHxwA)全部 492 张图片，按文件哈希为 483 份不同内容，共 5,887 帧。原始图像不经过 AI 重绘。
- 右键桌宠 → **表情与互动 · 上传 / 编辑**：按 `wx-0001` 这样的稳定编号搜索，选择缩略图看完整原动画，点击“在桌面播放”。
- 微信原图经多时点复核纠正 7 项分类；双人同框与重复角色场景继续作为整体播放，不拆到两个窗口里。
- 原有双人自动互动与顺序回应仍保留；本次增加的是单人原素材同时起播，不替代两只各自的随机表情。
- **停用此素材及关联互动**会持久保存选择，并停止正在播放的依赖互动；点击“恢复此素材”可恢复。原文件保留，便于日后根据编号精确删除或恢复。
- 静态待机直接裁切用户批准的 `preview-v3.png`。有已确认原素材的状态使用原动画；暂无对应素材的状态维持批准形象，不重绘补帧。原动画文字、道具、底色均保留；极短帧延迟设为至少 20ms。
- 源文件和编号目录见 [`content/wechat`](../content/wechat/README.md)，结构见[设计文档](../docs/plans/2026-10-11-wechat-library-design.md)。构建目录需要与 `Content/wechat` 一起分发；也可带 `--library` 参数启动直接打开素材库。

## 双角色互动

- 右键任意一只 → **和对方互动** → 默认六组精选搭配；在编辑器中可自行增减。
- 开启 **自动情侣互动** 后，两只会间隔一段时间主动靠近；也可把两只拖近触发抱抱。
- **布布跟着一二** 可单独开启，默认关闭。
- 双人播放时，按该素材记录的左右角色分配拖动对象；互动会立即停止。角色重叠或移动换位的原动画仍按记录的左右半区操作。
- **显示一二 / 显示布布** 可单独切换，至少保留一只；**回到屏幕右下角** 可重新集合。
- 两只共用一套健康/系统提醒与设置，不会各自重复发送相同提醒。
- 先前 AI 动作图集不再用于当前渲染；历史生成记录保留在 [素材记录](../docs/duo-asset-prompts.md)。

## 环境要求

- Windows 10 或 Windows 11（x64）
- .NET 8 SDK：开发与构建时需要
- 运行发布后的 self-contained 版本时不需要额外安装 .NET

## 构建与运行

推荐先在仓库根目录执行安装脚本：

~~~powershell
.\windows\install-windows.ps1
~~~

它会安装到 `%LOCALAPPDATA%\Programs\YierPet-Windows`，同时创建桌面快捷方式和开机启动快捷方式，并启动最新版本。

仅从源码构建并运行时，在仓库根目录执行：

~~~powershell
.\windows\build-windows.ps1 -Run
~~~

生成可分发的自包含版本：

~~~powershell
.\windows\build-windows.ps1 -Publish
~~~

发布结果在 `windows\artifacts\win-x64\`，须连同 `Content` 和 `Assets` 一起分发整个文件夹，启动 `YierPet.Windows.exe` 即可。退出应用请右键桌宠并选择“退出”。

## 使用

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 挥手打招呼 |
| 左键拖拽 | 移动桌宠，按拖动方向奔跑 |
| 快速甩出 | 重力、反弹与受击反馈 |
| 右键 | 切换动作、暂停随机行为、开关提醒、退出 |
| Alt + 右键 | 额外显示“测试提醒”菜单 |

## Windows 功能

- 透明、无边框、始终置顶且不显示任务栏图标
- 右键动作：站立、原图左右走路，以及每位角色五个常用表情；可在编辑器中自行增减
- 两只各自每隔约 4–8 秒尝试随机行为，80% 从各自已启用的单人表情库抽取、20% 走动；避免连续重复同一张。播放中的动作先完成，双人互动和本人用户操作优先。
- 一只正在播表情、被拖动或打开菜单，不阻止另一只独立播放。开启布布跟随后，布布也可以独立播表情，结束后继续跟随。
- 久坐、喝水、深夜、已知视频播放器前台停留提醒
- 上传 GIF / PNG，编辑动作说明、左右站位及多个联动候选；配置三个右键栏目，详见 [表情库使用说明](../docs/user-sticker-library.md)
- 提醒与随机行为开关保存在 %APPDATA%\YierPet-Windows\settings.json

## 隐私与限制

程序使用公开 Windows API 获取本机输入空闲时长、前台进程名；不申请屏幕录制或辅助功能权限。为避免读取浏览器内容，它不会判断浏览器内的具体视频网站；“摸鱼检测”只针对已知的视频播放器进程。
